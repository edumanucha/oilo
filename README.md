# Oílo · tus libros, contados

App gratuita para escuchar tus libros (EPUB, PDF, Word y TXT) como audiolibros, en castellano e inglés.
Funciona en el navegador del celular y se instala como app. Todo queda guardado en tu dispositivo.

- Voces naturales que corren en el celular, sin internet una vez descargadas
  ([Supertonic 3](https://github.com/supertone-inc/supertonic), con [Piper](https://github.com/rhasspy/piper) y las voces del sistema como alternativa).
- Biblioteca con tapas, progreso, marcadores, resumen de "¿dónde estaba?", anuncios de capítulo y temporizador para dormir.

## Desarrollo

```bash
npm install
npm run dev
```

Se publica sola en GitHub Pages con cada push a `main`.
